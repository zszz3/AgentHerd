- [x] 1.1 In a disposable project, use the installed stdio bridge with AgentHerd's client capabilities. - [x] 1.2 On the same real session, set a candidate approval mode and identify an authoritative confirmation of the effective mode. Repeat on load and same-profile replacement. Verify that a pending session, unreadable state or reported default cannot count as confirmation.
